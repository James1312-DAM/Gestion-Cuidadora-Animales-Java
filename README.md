Proyecto de java desarrollado durante 1.º DAM como parte de mi portfolio académico.

Aplicación de gestión de una cuidadora de animales desarrollada en Java.

## DESCRIPCIÓN ##
La aplicación permite a los clientes de una clínica veterinaria gestionar la ficha de sus 
mascotas, solicitar citas y comprar productos de alimentación y accesorios desde el móvil. 
Además, ofrece un panel para el personal veterinario donde gestionar citas, historiales 
clínicos y el catálogo de productos.

## TECNOLOGÍAS UTILIZADAS ##
  - Entorno: Intellij
  - Lenguaje: Java
  - Base de datos: Oracle Database (Oracle SQL Developer)
